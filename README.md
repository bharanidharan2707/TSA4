# Speech Emotion Detection

## About

An AI-based application that analyses voice recordings and predicts emotions from speech.

## Features

* Upload audio files.
* Analyse voice recordings.
* Detect emotions such as Happy, Sad, Angry, and Neutral.
* Display prediction results.

## Technologies

* Python
* Librosa
* Machine Learning
* Streamlit

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
